| 文件 | 作用 | 主要读者 |

## 2. 建议阅读顺序

```
① 部署与集成说明  ← 先明确参数从哪来、往哪接（20 分钟）
② 4 份专家提示词  ← 再进入逐份投放与调试
```

先看清集成全貌，再逐份投放提示词。

## 3. 使用路径

| 步骤 | 做什么 | 用哪份文档 |
|------|--------|-----------|
| 1 环境准备（P0） | 沙箱镜像、工具注册、存储挂载、配置下发 | ① |
| 2 计算链路对账（P1） | 手工串跑脚本，与基准逐字段对齐（不接模型） | ① |
| 3 编排与提示词上线（P2） | 状态机开发 + 提示词渲染注入，跑通完整任务 | ①② |
| 4 交互闭环（P3） | 前端（流式 + 选项卡片 + 结果预览）上线 | ① |

## 4. 提示词使用要点

- 4 份提示词开头的「注入参数」段是**给部署方的集成说明**，正文只引用参数符号
- 若平台支持运行时渲染：保留符号，由平台在会话启动时注入实际值（推荐）
- 若直接粘贴为提示词：需先把参数符号替换为实际值
- 提示词建议作为**版本化资产管理**，便于灰度与回滚，不要硬编码进业务代码
